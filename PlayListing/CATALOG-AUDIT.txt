0. HOW DRAWINGS ARE GENERATED
-----------------------------
One data book, two paint copies.

  VehicleCatalog.spec(launch) token-matches rocket/mission/provider.
  First match wins. More specific tokens (falcon heavy, long march 5) are first.
  Silhouette key is VehicleCatalog.drawFamily(launch), NOT family
    (catalog comment still says family; zq3 is the counterexample: family=zq, drawFamily=f9).
  Unmatched live rockets return private GENERIC (verified=false) and paint
    drawGenericVehicle plus a NEW VEHICLE · DATA UPDATE REQUIRED banner.

  CommandConsoleView.drawVehicle when (drawFamily):
    "f9","zq"  -> drawFalconVehicle(..., cores=1)
    "fh"       -> drawFalconVehicle(..., cores=3)
    "sls"      -> drawSlsVehicle
    "soyuz"    -> drawSoyuzVehicle
    "starship" -> drawStarshipVehicle
    "glenn"    -> drawGlennVehicle
    "electron" -> drawElectronVehicle
    "ariane"   -> drawArianeVehicle
    "lm5"      -> drawLmVehicle(..., wide=true)
    "lm"       -> drawLmVehicle(..., wide=false)
    else       -> drawGenericVehicle   <<< isro, h3, generic, anything unmatched

  RetroCommandWallpaperService.drawVehicle when (drawFamily):
    Same families, same drawers. Order differs (electron before glenn).
    Wallpaper sls/generic do not take a LaunchSnapshot; they use telemetryModule.tracked.
    Wallpaper Glenn / Starship / Electron are NOT pixel-identical twins (see diffs).

Shared primitives (both surfaces):
  drawOgive     quadratic nose/fairing. Control Y is (base + tip) * 0.45f
                That is a SUM, not a lerp. Screen-Y dependent. Can read as
                dual-peak / V-notch / "two nipples" when the stack sits low.
                Used by: Falcon fairing, SLS SRB, Soyuz shroud, Starship ship,
                Glenn S2, Electron S2, Ariane S2, LM/LM5 S2, Generic S2.
  drawRoundRect stage tubes
  drawVehicleBell  trapezoid + oval exit (Ariane / LM bells)
  drawCircle / engineDotLayout  engine dots, not noses
  drawOval      SLS upper/Orion payload cap (the leftover circle nose)
  drawStageTanks  LOX / fuel bars inside the tube
  drawBookGap   NEW VEHICLE banner when verified=false

There is no per-vehicle SVG/path asset. Every outline is code.

Circle noses are NOT used for every vehicle. Only SLS Orion is a true
drawOval fairing. Everything else that looks "pointy-wrong" is drawOgive
with the broken control-Y.

Wallpaper-only extras:
  Starship: plasma tile wash + four purple flap-glow circles when hot.
            No Pez deploy (console has drawPezRelease).
  Glenn: all-navy, no landing fins, 7 engines in a ring, 1 S2 flame,
         ogive halfW = w*1.05 on a body of w*0.85 (mushroom hat).
  Electron: thinner tube (h*0.038 vs console h*0.048).
