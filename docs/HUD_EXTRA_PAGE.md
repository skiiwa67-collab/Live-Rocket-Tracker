# HUD extra home page (patch note)

## 2026-09-04 — Razr system update

After a **Motorola Razr OEM/system update**, the extra home-screen page used for the LRT live-wallpaper HUD (eight plates) had to be **created again**. This is launcher/OS behavior, not an LRT stamp regression.

## Permanent tester note

After **any** phone OS or launcher update:

1. Recreate an extra home page if the launcher ate it.
2. Leave a **bait icon** on that page (YouTube or Alarm widget) so the page is not deleted as empty.
3. Double-tap Live Rocket Tracker → set live wallpaper → set HUD to **screen 1** (eight plates).

Stock Pixel glues the Google search bar to the first home page; packer measures the HUD page separately.
