## 9. Event tape — FAIL

Call site passes wall-clock time, not a tick counter: `drawTelMetrics` line 3328 `val t = telemetryModule.effectiveSecondsFromNet(now)` then `drawEventTimeline(..., t, ...)` at 3404. `effectiveSecondsFromNet` (`RocketTelemetryModule.kt:254-276`) is `(now - t0) / 1000f - trail` for a live bird. Pausing the activity tick does not freeze that value.

Prop-load hold: `propStart = -1800f` and `if (tSec < propStart)` draws only the prop-load gloss and returns (`RetroCommandWallpaperService.kt:3598-3609`). That is T-30 minutes.

Layout that does match the spec (fractions of the tape, not pixel slots):

- Past (`dt < -0.5f`) is forced left of center and drawn at `botY` (`3653`, `3668`).
- Upcoming outside the lead stays right of center, bottom, `boxH = tapeH * 0.16f` versus `0.24f + 0.14f * grow` on top (`3654`, `3663`).
- Last five seconds: `lead = 5f`, `soon = dt in 0f..lead`, `onTop` uses `topY`, grow is `1f - (dt / lead)` (`3617`, `3648`, `3660`).
- Positions: `topY = top + tapeH * 0.40f`, `botY = top + tapeH * 0.86f`, `xRaw` uses `tapeW * 0.46f` (`3618-3623`).

Fail: the center lock includes events that have not happened. `RetroCommandWallpaperService.kt:3647-3652`:

```
val past = dt < -0.5f
val soon = dt in 0f..lead
val now = dt <= 0.5f && !past
...
now -> cx
```

`dt = et - tSec`, so `dt` from 0 to 0.5 is still in the future, `past` is false, and `now` is true. The label is drawn at `cx` up to half a second before the event. Spec: nothing sits in the center until it happens. Center should start only once `tSec` has reached `et` (`dt <= 0`).

The vertical move is a snap to `topY` for the whole five-second window (`3668` `if (onTop) topY else botY`), not a slide from the bottom. Size does grow. The early center lock is the break.

`telFit` (`241-244`) then floors event text at 10px (`coerceAtLeast(10f)`) even though the new call passes a fractional `boxH` (`3666`). On the tape band's 24px minimum (`3343` `coerceAtLeast(24f)`), bottom text wants `0.16 * 24` px and is forced back up to 10. That fights "smaller" and "no fixed pixels."
